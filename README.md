# Trail Bajenting Cybersecurity Portfolio

Static HTML portfolio ready to deploy on Vercel.

## Preview locally
Open `index.html` in a browser. All evidence links point to files in `public/evidence/`.

## Deploy to Vercel
1. Extract this ZIP.
2. Create a GitHub repository and upload the contents of this folder (the `index.html` and `public` folder should be at the repository root).
3. In Vercel, choose **Add New → Project**, import the repository, and deploy as a static site. No build command is needed; use the repository root as the project directory.
4. Review the live website and test each evidence link.

## Privacy check before public deployment
The site includes the uploaded training documents as downloadable evidence. Inspect them for personal email addresses, usernames, sensitive screenshots, or other details before making the site public. Replace or remove any files you do not want public. The GoPhish and network lab documents should only be shared where authorized.
